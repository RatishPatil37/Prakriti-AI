# .agents/ui-design.md

## Brand strategy

Use Darukaa.Earth's existing visual language as inspiration:

- nature imagery;
- green botanical accents;
- editorial rhythm;
- scientific credibility.

Do not clone the existing marketing website.

## Product concept

Build an original AI Environmental Scientist workspace.

### Primary screen

Three regions:

```text
sidebar      scientist chat       evidence rail
```

### Evidence rail

Show:

- retrieved sources;
- environmental variables;
- impact metrics;
- confidence;
- citation links.

### Streaming state

Show meaningful progress:

```text
Reading context
Searching evidence
Connecting variables
Generating plan
```

Then stream answer tokens.

## Visual direction

Warm off-white + forest green + restrained lime accent.

Use typography and whitespace as the primary luxury signal.

Avoid:

- excessive glassmorphism;
- generic SaaS gradients;
- ten different card styles;
- oversized animations;
- stock AI robot visuals.
