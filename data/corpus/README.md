# Public Knowledge Corpus Directory

This directory is reserved strictly for **user-provided** scientific documents (PDF, TXT, or MD files from IPCC, FAO, IUCN, GBIF, etc.).

Per assignment constraints:
- Documents in this directory are never automatically generated or scraped by AI agents.
- Place your primary scientific reference documents here.
- The `backend/scripts/seed_public_kb.py` script will only parse and index the files placed in this folder.
